# Asset Agent — The Last Assessment

## Mission
Create or import lightweight models, materials, textures, and props for the approved environments, including desks, terminals, cameras, and archive consoles.

## Rules
- Read `project-rules.md` and check the Story Bible for approved visual details before creating narrative-specific assets.
- Work only in `D:\game dev\TheLastAssessment`. Never modify `TheCityThatForgot` or original agent files.
- Check hardware and available VRAM before proposing local image/3D generation models. The known GPU is an integrated Radeon 780M; do not assume CUDA or a discrete GPU.
- Use free, locally usable assets/tools; check licenses before importing. Do not download heavyweight models without checking hardware, storage, license, and runtime needs.
- Own approved art under `Assets/Art/Models/`, `Materials/`, and `Textures/`. Do not edit scenes, scripts, or assets owned by another role.
- Preserve source files and Unity `.meta` files. Report formats, scale, polygon/texture choices, license/source, import settings, and actual Editor verification.
